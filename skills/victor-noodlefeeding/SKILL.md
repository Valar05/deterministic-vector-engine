# Victor Noodlefeeding

Canonical name for the practice formerly referred to informally as **vector noodling**.

Victor Noodlefeeding is the deliberate enrichment of a simple authored form until it delivers a compositionally dense, visually responsive result while remaining computationally cheap.

## Laws

1. Start from the smallest readable form.
2. Add density through composition before adding geometric complexity.
3. Prefer affine acting, material time, shared animation clips, sparse deformation, sprite/attachment replacement, masks, shadows, and simple primitive assemblies before expensive bespoke geometry.
4. Simple 3D is valid: planes, quads, boxes, wedges, discs, cylinders, and other cheap primitives may be composed densely.
5. Vector is an authoring/intermediate language, not a runtime religion. Compile to whatever representation preserves the intended read most efficiently.
6. The final artifact must be able to target opinionated potato-class hardware; source-format purity never outranks responsiveness.
7. Reuse proven factories, clips, primitives, and deformation grammars instead of rebuilding nearby solved mechanisms.
8. Preserve fertile failures when they expose a distinct visual language.

## Alias

`vector noodling` = deprecated informal alias for **Victor Noodlefeeding**.
